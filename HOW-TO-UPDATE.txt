================================================================================
  ENCRYPTED CREW - NIGHTHAWK: How to Update/Repair
================================================================================

QUICK FIX (One Command):
------------------------
nighthawk repair --force


INTERACTIVE UPDATE:
-------------------
nighthawk repair


UPDATE FROM SPECIFIC BRANCH:
-----------------------------
nighthawk repair --branch main


VERIFY INSTALLATION:
--------------------
nighthawk --version


MANUAL METHOD (If repair command fails):
-----------------------------------------

Windows PowerShell:
  pip uninstall nighthawk -y
  pip cache purge
  pip install --no-cache-dir git+https://github.com/Xenoz-GitHub/NightHawk.git@encrypted-crew-v2
  nighthawk --version

Linux/macOS:
  pip uninstall nighthawk -y
  pip cache purge
  pip install --no-cache-dir git+https://github.com/Xenoz-GitHub/NightHawk.git@encrypted-crew-v2
  nighthawk --version


COMMON ISSUES:
--------------

Issue: "Command not found after repair"
Fix: Close and reopen your terminal, then try again

Issue: "Permission denied"
Fix (Windows): Run PowerShell as Administrator
Fix (Linux/macOS): Use pip install --user

Issue: "Connection error"
Fix: Check internet connection and try again
